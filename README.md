# FS25_NFMarschRealistic

DE: Dieser Mod ändert die für mich unrealistischen Dinge auf der NF Marsch. Nicht mehr und nicht weniger. Angepasst wurden bisher u. a. Palettengrößen, Produktionsgeschwindigkeit/-kosten/-lagermengen und die Preise der vorplatzierten BGAs. Tiere werden bewusst nicht angepasst (siehe M+). Vorschläge gerne über GitHub-Issues.

EN: This mod changes the things on the NF Marsch that are unrealistic for me — no more, no less. So far this includes pallet sizes, production speed/cost/storage amounts, and the price of the pre-placed biogas plants. Animals are intentionally left untouched (see M+). Suggestions welcome via GitHub issues.
